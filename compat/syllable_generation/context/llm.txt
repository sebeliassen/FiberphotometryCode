# Project Context: syllable_generation

## VFI (Video Frame Index) Synchronization Rules
When syncing Keypoint MoSeq (KPMS) results with photometry data and behavioral videos, follow these established rules:

1. **VFI represents Ground Truth Absolute Frames**: The `VFI` (Video Frame Index) arrays generated by the `keypoint_moseq` library (stored in `video_frame_indexes.npz` or exported alongside raw results) map the tracked DataFrame rows DIRECTLY to the physical absolute frame indexes of the original video.
2. **1:1 Mapping**: When extracting snapshots or creating videos from the `all_data_df` where photometry and kinematics are merged, use `v_idx = int(row['frame_index'])` natively. **Do not apply any arbitrary scaling factors (like multiplying or dividing by 2).** 
3. **Subsetting Constraints**: Because the KPMS extraction pipeline subsets data dynamically based on "activity" constraints, the maximum index or length of a `VFI` array will often be much lower than the expected session length (e.g., ~50%). **Never use naive `vfi.max() < expected_length` heuristics to deduce downsample rates**, as this will result in false positives and double-scaled indices for subsetted data.
