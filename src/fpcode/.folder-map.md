## Sub-Modules
- [`adapters/`](./adapters/.folder-map.md): Adapters translating external formats (DeepLabCut, legacy pickles, session dictionaries) into canonical contracts.
- [`alignment/`](./alignment/.folder-map.md): Time-axis synchronization, sensor resampling, and monotonic frame timestamp mapping algorithms.
- [`behavior/`](./behavior/.folder-map.md): Behavioral kinematics calculation, heading smoothing, and typed syllable bout segmentation.
- [`cli/`](./cli/.folder-map.md): Unified command-line interface entry points for training, validation, export, and diagnostics.
- [`common/`](./common/.folder-map.md): Low-level utilities for structured logging, filesystem I/O, cache manifests, and configuration validation.
- [`compat/`](./compat/.folder-map.md): Isolated backward-compatibility delegation shims preserving historical pickling and notebook imports.
- [`contracts/`](./contracts/.folder-map.md): Foundational dataclass records, timeline coordinates, pose series, and serialization protocols.
- [`kpms/`](./kpms/.folder-map.md): Keypoint-MoSeq probabilistic generative modeling (AR-HMM/SLDS), model initialization, and training wrappers.
- [`photometry/`](./photometry/.folder-map.md): Photometry preprocessing (dF/F, detrending), event window extraction, and baseline response metrics.
- [`statistics/`](./statistics/.folder-map.md): Statistical estimators, circular smoothing, bootstrap resamplings, and signal summary metrics.
- [`tracking/`](./tracking/.folder-map.md): Multiview 3D camera correspondence, static spatial registration, and multi-camera fusion.
- [`viz/`](./viz/.folder-map.md): Scientific visualization suite: syllable grid movies, trajectory plots, pose geometry overlays, and figures.
- [`workflows/`](./workflows/.folder-map.md): Cohesive multi-stage pipelines: multimodal analysis, session exports, model training, and movie rendering.
