# Strict Objective Ethological Nomenclature

1. **Do not assign subjective or functional ethological labels** (e.g., "grooming mode", "exploration mode", "foraging", "strategy", "stereotypy as a motif") to unsupervised syllables, clusters, or NMF components.
2. **Use objective physical, kinematic, or statistical descriptors instead**:
   - Velocity/speed (e.g., "low centroid velocity", "high speed movement")
   - Spatial distribution (e.g., "wall-localized/thigmotaxic", "center/spatially dispersed")
   - Elevation/posture (e.g., "high vertical displacement", "low elevation")
   - Component nomenclature: "Component k", "Mode m"
   - Information theory: "constrained state entropy", "non-Markovian history gain $\Delta_{\text{history}}$"
3. Reference full guidelines in `studies/language_models/mds/01_theory_and_strategy/04_objective_ethological_nomenclature_guidelines.md`.
