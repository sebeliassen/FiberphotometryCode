## Design points (Codex)

1. **Compat code lives inside the canonical library**: `viz/v2.py`, `viz/geometry.py`, `viz/legacy_*.py`, `photometry/metrics.py`, `statistics/summary.py`, `common/schemas.py`.
   - Move these into one `fpcode.compat` subpackage and add an audit rule that nothing outside it imports it.
   - `schemas.py` still has `PathConfig` with hardcoded `/home/fsp585` defaults. That is the one hardcoded path inside `src`, and the report says there are none.
2. **The layer matrix is more permissive than the real graph.**
   - `viz→kpms` and `kpms→photometry` are allowed but unused. Tighten `LAYERS` to the actual edges so new ones fail.
   - `tracking.fusion` imports `behavior.kinematics`, which is the wrong direction. Push kinematics primitives down.
   - `kpms.export` forwards up to `workflows.session_export` through a whitelist. Pick one owner and delete the exception, because "zero upward dependencies" isn't strictly true today.
3. **Misplaced or overlapping modules.**
   - `common/io.py` holds `compact_kpms_checkpoint`, which is domain logic. It belongs in `kpms/checkpoints.py`.
   - `kpms/metrics.py` is syllable-frequency statistics, so it belongs in `behavior` or `statistics`.
   - `photometry/alignment.py` is a DataFrame merge that collides with the real `alignment/` package, so rename it.
   - Several modules still carry stale docstrings from the migration (`tracking/clock_sync.py` says "core.ttl_sync").
4. **Cohort calibration JSON ships inside `tracking/`.** Your own contract says studies own cohort choices, so these belong in `configs/` and should be passed in explicitly.
5. **Replace the ~650 generated shim files with one `sys.meta_path` finder** driven by `SHIMS.tsv`. That gives a single source of truth, one place for telemetry, and a removal that is just a deleted table row.
6. **Typing, CI and packaging.**
   - There is no `.github/` CI and no `py.typed`.
   - `make lint` doesn't cover `studies` or `tests`.
   - The distribution is `fiberphotometry-suite` but the import name is `fpcode`.
