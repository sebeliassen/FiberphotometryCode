with no equivalent tuning evidence found. The original fitting prefixes and
concatenation policy are historical facts, not the Karen execution policy.

## 2. Recover how the themes became interpretable

Configuration links themes A/B/C to grouped motifs 7/4/1. Later definitions
evolved into rear/sniff/descent/depart, right-turn locomotion and stationary
sniff/rest examples. Final movies retrieve specified complete observed paths,
filter durations/tracking, choose local/background-density exemplars in a
posture/speed representation, then choose neighbours and presentation panels.
Those final renderers do not require W/H factor detections.

Thus transfer **generator-suggested, explicitly refined themes**, with an ordered
core and listed variants. Preserve the distinction between a factor, a refined
theme's full occurrence population and its selected movie examples. Selected
exemplars alone cannot establish full-population coherence.

## 3. Produce a small Karen theme library

Start from the already-fitted pooled K10/K18, three/five-bout catalogues on all
99 recordings/21 mice. Use human syllable names, supported actual observed paths
and prior qualitative feedback to propose a few distinct themes. Aim for roughly
3–6 if supported; do not force IFxDN's themes or three families onto Karen.
Use coherent common cores with explicit alternative endings/substitutions;
avoid one family per exact string or treating a template's argmax as observed.

Freeze proposed definitions before comparing PFF with monomer. Retain full factor
calls separately and record each theme's source, constituent membership, accepted
variants, boundaries, mouse support and union time coverage. Retrieve theme/core
occurrences throughout valid recordings when measuring continuations, rather
than restricting denominators to successful factor detections.

If existing fits yield no useful candidates, use **one bounded coarse-vocabulary
adaptation** inspired by K8/L5/lambda0.5/100updates/seed42. Karen already has broad
human-label mappings; retain unresolved IDs separately, preserve raw constituents
for intra-theme analysis, and keep exclusion/missing-data barriers. Fit one shared
generator over all eligible recordings. This is a fallback, not another search
or an exact IFxDN replication; the current grouped69 view is not its 14-token input.

Render only the shortlist: six-execution 2x3 p100/P80/random movies with the
preferred corrected ranking, natural timing, onset-fixed camera and syllable
colours. A tiny final sanity check replaces a full generator-review programme.
Unreviewed themes remain provisional; report mixed or indistinct candidates too.

## 4. Readouts from the frozen theme library

| Analysis | Measurements and comparisons |
| --- | --- |
| Recruitment and catalogue-wide organisation | Events/minute, union time fraction, duration, initiation rate, theme composition/diversity and mouse support; overall and per theme |
| Intra-chain execution | Stage/whole duration, pacing, speed, angular velocity, displacement and constituent substitutions/omissions/repeats; the same syllable inside versus outside a theme |
| Branching and progression | Alternative continuations after an explicit shared root, progression/observed exits and group-dependent variant frequencies; use all eligible root opportunities |
| Inter-chain combinations | A-to-A repetition, switching, run lengths, A-to-B transitions and A-to-B-to-A returns; overall and supported theme-specific effects, with explicit overlap/gap/barrier rules |
| Context and sequence controls | Does execution depend on preceding/following theme? Does repetition exceed frequency-only expectations or first-order organisation? Compare chain readouts with constituent usage and movement baselines |
| Optional photometry | Existing processed Jonathan-WT-only DA associations at onset/stage/branch transitions; preserve signal suffix/region/source support. Karen has no equivalent available DA here |

For Karen compare PFF versus monomer by observation wave, pooled untreated waves
and within-mouse longitudinal changes; report L-DOPA separately because drug,
age and wave are confounded. IFxDN reference analyses instead concern WT/KI,
saline/amphetamine and their interaction. Do not combine numerical state IDs or
effect estimates across datasets. Independent N is mice, not clips or calls.

First deliver recruitment, intra/branching and basic inter-chain readouts.
Higher-order context/null diagnostics follow where opportunities support them;
DA is secondary and does not delay the Karen deliverable. Reuse current robust
timeline/statistical owners, not the historical sparse pooled fallbacks.

## 5. Report signals before and after correction

Export every tested endpoint/contrast with mouse N/opportunities, effect size,
uncertainty, raw p, within-analysis-family BH q and disclosed broader correction.
Show corrected survivors, nominal-only signals and coherent nonsignificant
tendencies. If nothing survives correction, state that plainly and retain the
descriptive themes and pilot effects. Label post-hoc theme refinement and prior
data exposure; do not tune definitions to smaller p-values or present selected
examples as independent confirmation. A small set of themes does not make all
their many endpoints one small test family.

Existing dated reports show this is feasible: one IFxDN exploration contrast
reports p=0.0172/q=0.1380; an older Karen L2 repetition-excess contrast reports
p=0.0334/q=0.844. These are recovery leads from their own dated catalogues, not
new findings for current Karen fits. Recompute new library statistics. Verify
source tables before promoting old report values to final figures.

Final package: a compact theme atlas, several readable figures, full statistical
tables and a brief methods/provenance/handoff document. Preserve current worktree
and experimental work; no new branch or cleanup is needed for this planning step.
