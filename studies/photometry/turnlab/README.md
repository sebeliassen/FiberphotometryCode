# TurnLab Behavioral Photometry Study

**Location**: `studies/photometry/turnlab`  
**Status**: `ACTIVE`  
**Standard**: Conforms to [`docs/architecture/UNIT_CONTRACT.md`](../../docs/architecture/UNIT_CONTRACT.md)  

## 1. Purpose
Investigates turning dynamics, trajectory curvature, and neural signal correlations during locomotion initiation and turning bouts.

## 2. Inputs
Synchronized photometry traces and MoSeq syllable annotations

## 3. Outputs
Turn bout segmentation, trajectory plots, cross-correlation maps

## 4. How to Run
```bash
python experiments.py
```
